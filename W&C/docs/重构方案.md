# W&C 工作台 · 重构方案

> 创建：2026-10-22 ｜ 从旧版 WorkBuddy 单文件 `index.html`（2492 行）重构而来
> 定位：双人减脂 + 生活工作台（减肥记录 + 鲸闻），PWA，长在手机里

## 一、技术决策

| 项 | 决策 | 理由 |
|---|---|---|
| 形态 | 纯静态 PWA（无构建工具） | 沿用现有部署方式，换文件即更新，好维护 |
| 代码组织 | HTML / CSS / JS 分离，多文件 | 告别 2492 行单文件 |
| 本地数据 | localStorage | 沿用 |
| 云同步 | Upstash Redis（`/set/wc_data`、`/get/wc_data`） | 沿用，双人跨设备同步 |
| 文本 AI | DeepSeek（`deepseek-chat`） | 修复默认 model 错误 |
| 视觉 AI | 通义千问 `qwen-vl-max-latest` | 拍照识食，沿用 |
| 部署 | 静态托管（沿用现有方式） | 待确认具体平台 |

## 二、目录结构

```
W&C/
├─ index.html          # 唯一入口，只放页面骨架
├─ manifest.json       # PWA 清单
├─ sw.js               # Service Worker
├─ css/
│  └─ style.css        # 全部样式（变量/组件/模块）
├─ js/
│  ├─ app.js           # 状态、路由、启动
│  ├─ storage.js       # localStorage + 云同步(Upstash)
│  ├─ ai.js            # 文本/视觉 AI 调用
│  ├─ render.js        # 各模块渲染
│  └─ data.js          # 常量、默认数据、迁移
├─ icons/              # 图标
└─ docs/
   └─ 重构方案.md       # 本文档
```
